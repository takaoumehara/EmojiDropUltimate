## 必須（これが無いとページが作れない）

### Q1. 掲載カテゴリーは Interactive Experience でよいですか

- **どこの何か**: README §1「掲載カテゴリー」。どの索引ページに載るかが決まります
- **なぜ分からないか**: 2つ成立してしまうため。
  - **Interactive Experience** — 定義が「その場の全端末が入力になるもの」で、この作品の核（1〜4台のスマホが常駐サーバー無しで繋がる）とほぼ一致する。**こちらを仮に選んであります**
  - **AI Products** — ステージ生成に Gemini を使っている（`api/ai-stage` → `src/aistage.js`）。ただしAIは1機能であって、作品の identity ではないと判断しました
- **どう答えれば埋まるか**: 「Interactive でよい」か「AI Products にする」の二択でお答えください。
  Interactive のままなら、**入力ラベルは `Every phone` を提案しています**（これも変更可）

### Q2. 役割の表記をどう書きますか

- **どこの何か**: README §1「自分の役割」
- **なぜ分からないか**: 実装はほぼ全量をAIセッションが書いていて、本人は方向決めと却下を担当している、という構図しかリポジトリからは読み取れません。**これをどう名乗るかは本人の看板の問題**なので、こちらで決めるべきではないと判断しました
- **どう答えれば埋まるか**: 以下から選ぶか、ご自身の言葉で。
  - `Game Designer / Creative Director（AI-assisted implementation）` ← 実態に一番近いと思われます
  - `Solo Developer`
  - `Game Designer & Developer`
  - ※ §6.5 Craft で「AIに何をさせ、何がダメだったか」を具体的に書いてあるので、AI を使ったことを役割名で隠す必要はないと思います

### Q3. 公開URLはどれを載せますか

- **どこの何か**: README §1「公開リンク」
- **なぜ分からないか**: Vercel の本番ドメインは `emoji-drop-ultimate.vercel.app` と推測されますが、**このセッションからは外向きのプロキシがデプロイ先を通さず、実際にアクセスして確認できませんでした。** 独自ドメインを当てている可能性もあります
- **どう答えれば埋まるか**: 載せてよいURLを1つ。「リポジトリだけでいい」でも構いません

### Q4. アクセント色

- **どこの何か**: README §12
- **なぜ分からないか**: Interactive の指定色（ティール `#0d9488`）は konosaki 系が既に使用中で、重複してよいかが分かりません

  ゲーム画面の基調はベルの金と盾の赤なので、どちらでも画面と喧嘩はしません

### Q5. ホストの上り通信量の数字を載せますか

- **どこの何か**: README §9 に**あえて載せませんでした**
- **なぜ分からないか**: `docs/versions.md` に「2,211バイト × 15Hz × 3 ≒ 100KB/秒」という実測が記録されていますが、**いつ測ったかが書かれていません**。ヒアリング指示書の「日付の無い数字は載せない」に従って外してあります
- **どう答えれば埋まるか**: 測定日を覚えていれば教えてください。分からなければ**このまま載せない**のが正しいと思います（必要なら測り直します）

### Q6. 「およそ15秒で全員つながる」を載せてよいですか

- **どこの何か**: README §9 の「誰の・何を動かしたか」の一文
- **なぜ分からないか**: 出典は実 Chromium 4枚での試行4回（3回が15秒前後、1回は81秒）で、**同じ1台の中の話です。実機・携帯回線では未検証。** 注記は付けてありますが、ポートフォリオに出す数字としてどこまで許容するかは判断が要ります
- **どう答えれば埋まるか**: 「注記付きで載せてよい」/「実機で測るまで外す」のどちらか

### Q7. Retrospective の3つ目を残しますか

- **どこの何か**: README §10 の3つ目「説明書が要った時点で、答えが出ている」
- **なぜ分からないか**: 直前に作ったばかりの機能を自己批判する内容なので、**ポートフォリオとして誠実に見えるか、単に自信が無く見えるか**の線引きは本人の感覚によります。個人的には一番良い項目だと思っていますが、押しつけたくありません
- **どう答えれば埋まるか**: 「残す」/「外す」
