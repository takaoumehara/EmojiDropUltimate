## 3. ③ の撮影指示

### 【撮影指示】T-1 プレイ画面のスクリーンショット一式 ★最優先

- **何を写すか**: ①タイトル（章とマップが出ている状態）②キャラ選択（**鍵と「あと◯ステージ」が
  見えている状態**・これがこの案件の主張そのもの）③6面それぞれの道中（**進行方向が違うことが
  分かる4方向を必ず含める**）④ボス戦（HPバーが出ている状態）⑤ふたりで遊ぶロビー
  （QR・あいことばが出ている状態）
- **使う道具**: スマホの画面収録またはスクリーンショット（iOS: サイドボタン+音量上 /
  Android: 電源+音量下）。PC のブラウザでも可ですが、**この作品はスマホ縦持ちが正**なので
  スマホを推します。
- **手順**:
  1. スマホで `index.html` を開く（ローカルHTTP でも、公開URLがあればそれでも可）。
  2. タイトル → キャラ選択 の順に撮る。**キャラ選択は、鍵が残っているうち（=全部開放される前）に
     撮ること。** 全部開いた後では二度と撮れません。
  3. 1面から順に遊び、各面の道中で1枚・ボスで1枚。
  4. タイトルに戻り「👥 ふたりでプレイ」を開いてロビーを1枚。
  5. 端末から書き出す。
- **出力**: スマホの解像度のまま PNG ／ `emojidrop-shot-01.png` 〜 `-14.png` ／
  **加えて、一番よく写っている1枚を 760×570（4:3）に切って `thumbs/emojidrop.jpg`**
- **失敗しやすい点**: **キャラ選択を全開放後に撮ってしまうこと。** 鍵と「あと◯ステージ」が
  写っていない画面は、このケーススタディでは価値が半分になります。次点は、
  スマホの時計・電池・通知が写り込むこと（気になるなら機内モード + おやすみモード）。
- **所要時間の目安**: **30分**

### 【撮影指示】T-2 ソロの画面収録（方向が変わる瞬間）

- **何を写すか**: **面が切り替わって、進む向きが変わる瞬間**。最低2回（例: 1面 ⬆️ 上 → 2面 ➡️ 右、
  2面 ➡️ 右 → 3面 ⬇️ 下）。指がどう動いているかも見えると理想ですが、画面だけでも成立します。
- **使う道具**: iOS ならコントロールセンターの画面収録、Android なら標準の画面録画。
- **手順**:
  1. 機内モード + おやすみモードにする（通知バナーが被ると撮り直しです）。
  2. 画面収録を開始し、1面のボスを倒すあたりから回す。
  3. **面が切り替わる演出と、切り替わった直後の10秒**を必ず入れる。
  4. 2面 → 3面でもう一度同じことをする。
  5. 停止して書き出す。
- **出力**: 9:16 縦 ／ **20〜40秒**に詰める ／ 1ファイル `emojidrop-solo.mp4` ／
  ポスター画像 `emojidrop-solo-poster.jpg`（方向が変わった直後の1フレーム）
- **失敗しやすい点**: **切り替わりの前を長く撮りすぎること。** 20〜40秒に収めると、
  道中は各5秒しか入りません。**切り替わりの瞬間だけを2回**、が正解です。
- **所要時間の目安**: **30分**

### 【撮影指示】T-3 2台のスマホの協力プレイ（合成1本）

- **何を写すか**: 2台のスマホで同じ世界を遊んでいるところ。**相方の機体が自分の画面に飛んでいる**
  ことと、**2機のあいだに線（きずな）が張って、線に触れた敵が切れる**ところまで。
  合流（QR / あいことば）の一瞬も頭に入れると、話が早くなります。
- **使う道具**: **端末A = 自分のスマホの画面収録**（ホスト側）／
  **端末B = もう1台のスマホの画面収録**（ゲスト側。2人目が居ない場合は自分で交互に操作しても、
  短時間なら成立します）／ 編集 = iMovie でも可。
  ※ 機材が違う場合は `OPEN-QUESTIONS.md` Q-6 に回答してください。
- **手順**:
  1. 2台を同じ Wi-Fi につなぐ（**直結の成功率が一番高い**）。
  2. **両方の画面収録を先に回し始める。**
  3. **同期マーカー**: 合流した直後に、**ホスト側で1回だけボム（ダブルタップ）を撃つ**。
     画面全体が光る一瞬が**両方の記録に同時に写ります**。編集ではこのフレームで頭を揃えます。
  4. そのまま 60〜90秒 遊ぶ。**2機を近づけて線を張り、敵の列を線で切る**場面を最低2回入れる。
  5. 両方を止める。
- **出力**: 9:16 縦（スマホ画面が2つなので縦の分割が素直）／ **20〜40秒**に詰める ／
  **上下の分割、または片方を主・もう片方を小窓** ／ **1ファイル** `emojidrop-composite.mp4` ／
  ポスター画像 `emojidrop-composite-poster.jpg`（線が張っているフレームを1枚）
- **失敗しやすい点**: **同期マーカー（手順3）を忘れると、後から頭を合わせる基準が無くなります。**
  ここだけは絶対に外さないでください。次点は「線が一度も張らない」——
  2機が離れすぎると切れるので、**意識して近づける**必要があります。
- **所要時間の目安**: **半日**（撮影30分＋編集）

### 【撮影指示】T-4 2台が並んでいる実機写真

- **何を写すか**: 机の上に2台のスマホが並び、**片方の画面のQRコードを、もう片方がかざして
  読んでいる**ところ。あるいは2人が並んで遊んでいる手元。**両方の画面の中身が読めること。**
- **使う道具**: 3台目のスマホ、またはカメラ（人物モードは使わない。背景がボケると画面が読めません）。
- **手順**:
  1. 部屋の照明を少し落とす（画面が暗色なので、明るすぎると白っぽく飛びます）。
  2. 2台を並べ、片方にQRを出す。斜め上から1枚・真上から1枚。
  3. 遊んでいる状態でも同じ2構図。
  4. 各構図3枚ずつ。ブレるので多めに。
- **出力**: **4:3** ／ 横位置 ／ JPEG 最高画質 ／ `emojidrop-photo-01.jpg` 〜 `-05.jpg`
- **失敗しやすい点**: **画面への映り込み。** 蛍光灯やリングライトが画面に映ると中身が読めません。
  **光源が画面に映らない角度を先に探すこと。** 露出は画面に合わせ、机が暗く沈むくらいで正解です。
- **所要時間の目安**: **10分**
