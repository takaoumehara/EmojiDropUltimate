# 🚀 EMOJI DROP ULTIMATE

方向がガラッと変わる絵文字シューティング。ツインビーにインスパイアされた、スマホ/デスクトップ両対応のブラウザゲーム。

**▶ 遊ぶ:** `index.html` を(ローカルHTTP または Vercel/GitHub Pages で)開くだけ。ビルド不要・依存CDNなし。

---

## 🎮 特徴

### 📖 章(チャプター)で進む
6ステージ = 1章。全制覇すると**勝利演出 → 次の章が開放**され、章ごとに違う6つの世界が
(章が進むほど手強く)出てくる。第1章は手書き、第2章以降はテーマを重複なく決定論生成するので、
**誰がいつ遊んでも「第N章のM面」は同じ内容**。進行はブラウザに保存され、タイトルは
「つづきから」に変わり、制覇マップで到達度が一目で分かる。

### 🕹 キャラクター選択(6体)
遊ぶ前に自機を選ぶ。**弾も性能も別物**:
🚀ロケット(バランス)/ 🐱ネコ(移動最速)/ ⚡カミナリ(連射)/ 🍕ピザ(横に広い)/
🦄ユニコーン(貫通)/ 💩ウンチ(当たった敵が減速)。
※ ここの絵文字は**敵として絶対に使わない**(自分がどれか分からなくなるため)。

### 🎯 集中モード
その場に踏みとどまると連射が上がり、移動が遅くなる。撃つボタンを増やさずに
「攻めるか避けるか」の判断を作るための仕組み(スマホは指1本が移動で塞がるため)。

### 🤖 AIシステム(3本柱)
1. **AI World Engine(リアル天気連動)** — [Open-Meteo](https://open-meteo.com/)(キー不要)で現在地の天気を取得し、ゲームルールを書き換える: ⛈️落雷 / ❄️敵減速 / 🌧️活性化 / 🌫️視界不良+スコア / 💨弾が流れる / 🌙ナイトモード。オフライン時は標準モードにフォールバック。
2. **AIディレクター(動的難易度調整)** — 命中率・撃破ペース・被弾を観測してスキルを推定し、湧き・射撃頻度・支援ベルをリアルタイム調整。
3. **学習するボス** — プレイヤーの移動速度と「よく居る場所」を学習し、フェーズが進むほど偏差撃ち・置き撃ち(🧠が思考の合図)。

### ✨ AIステージ生成(LLM)
タイトルの **「AIステージを生成」** で、Gemini がその場でユニークなステージ(名前・配色・敵絵文字・ボス・方向)を **LIVE生成** して遊べる。現実の天気がテーマのヒントに使われる。**サーバー未接続/オフライン時は端末内で手続き生成にフォールバック**するので、キーが無くても誰でも遊べる。

### ♾️ エンドレスAI・🗓 デイリー・📸 共有・🏆 ランキング(やみつき&拡散)
- **♾️ エンドレスAI** — クリアするたびに次のワールドを生成して無限連戦(段階的に難化)。第1ワールドはGemini生成、以降は端末内で即生成。到達ワールド数がスコア。
- **🗓 デイリーチャレンジ** — 日付シードで**全員が同じステージ**を挑戦(Wordle方式)。`?seed=xxxx` で任意ステージを再現・共有。
- **📸 スコアカード共有 + SNSワンタップ** — 「ランク・スコア・到達ワールド・今日の天気・ステージ名」を1枚画像化。**X / LINE / Facebook / Instagram / TikTok / ネイティブ共有 / 画像保存 / リンクコピー**に対応。OGP画像(`og.png`)でSNSリンクのプレビューも綺麗に。
- **🏆 匿名デイリー・ランキング** — スクリーンネーム(任意・個人情報なし)+スコアだけを Vercel KV に保存し、その日の上位を表示。
- **🔥 ストリーク(連続日数)** — 連続プレイ日数を記録。途切れそうな日はタイトルで「今日プレイで継続」と促す(戻る動機)。
- **💾 セーブ(アカウント不要)** — 章の進行・統計・ストリーク・選んだキャラ・スクリーンネームを localStorage に保存。**ストレージが使えない環境(Safari プライベート等)でも落ちず**、保存だけ無効になる。

### 🎨 テーマ連動の演出
- **自機・弾がテーマ連動** — ステージのテーマに合わせて自機のエンジン光・噴射炎・弾の色が変化(シルエットは不変なので迷わない)。ステージが変わると色が**なめらかに補間**して切り替わり、発砲時にはテーマ色の**マズルフラッシュ**。AI/デイリー/エンドレスの生成ステージも配色から自動でテイントを決定。
- **アダプティブBGM** — テーマ毎に音色パレット(リード/ベース/パッド)が変わり、コンボ・残機ピンチ・ボスで**緊張度に応じてレイヤー(ドラム→ベース→パッド→主旋律→緊張音)が増減**する。外部ライブラリ・APIキー不要、オフラインでも鳴る。

### 👥 みんなでプレイ(リアルタイム協力・最大4人)
- タイトルの **「👥 ふたりでプレイ」** → 招待は3通り: **QRコードをかざす / あいことば(6桁) / リンクを送る**(`?join=CODE` で開くと自動合流)。QRは外部ライブラリなしの自前エンコーダ(`src/qr.js`)。→ **WebRTC DataChannel で端末同士が直結**(遅延 20〜80ms・ゲーム中サーバー不経由)。ホストは遊ぶ面(オリジナル/AI生成)を選べる。
- **相方の機体が自分の画面にリアルタイムで飛ぶ**(名前つき・**相方が選んだキャラの姿**で、弾も見える)。自分の足元には「じぶん」の輪が出る。
- **世界はホストが正**(ホスト権威)。敵・弾・ベル・ボスはホストだけが計算し約15Hzで配信、ゲストは補間して映す。自機と自分の弾はローカルなので**操作は遅延ゼロ**。各端末で別々に乱数・難易度調整・天気を回すと必ずズレるため、この形にしている。
- **ボスHPは共有プール**で貢献割合をライブ表示。**残機はチーム共有**なので片方だけ取り残されない。**ボスはソロの倍以上に巨大**。遊ぶ面は **📖 オリジナル / ✨ AI生成** からホストが選択。
- **3人・4人**も同じあいことばで入れる(中継サーバーを立てた場合)。人数に合わせて**残機が1機ずつ増え**、**ボスHPが1.11倍ずつ硬くなる**。
- **直結できない回線でも繋がる**: 中継サーバー(`server/`・依存ゼロ・任意)を立てて `index.html` に一行書くと、直結と**同時に**試して繋がった方で始まる。直結できる相手との速さは変わらない。立てなければ従来どおり直結だけで動く。
#### ⚙️ オンライン対戦を有効にする(Firebase は不要・約2分・無料)
「オンライン対戦サーバーが未接続です」と出る場合は、Vercel に KV(Upstash Redis)を接続するだけ:
1. Vercel のプロジェクト → **Storage** タブ → **Create Database** → **Upstash for Redis** を選ぶ(無料プランでOK)
2. 作成したストアを**このプロジェクトに Connect**(Production / Preview / Development すべてにチェック)
3. **Deployments → 最新のデプロイを Redeploy**(環境変数は再デプロイで初めて反映される)

これで `KV_REST_API_URL` / `KV_REST_API_TOKEN`(または `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`)が自動で入り、**QR・あいことば・招待リンクのすべてが有効**になります。同じストアが匿名デイリー・ランキングにも使われます。
※ サーバーが預かるのは接続情報(SDP)だけで**5分で自動消滅**します。ゲーム中の通信は端末同士のP2Pなのでサーバーを通りません。

#### 「直接つながれませんでした」と出る場合(TURN中継)
携帯回線同士など**厳しいNAT**の環境では、端末同士の直通トンネルが張れないことがあります(WebRTC共通の制約)。その場合は **TURN(中継サーバー)** が必要です。
- 既定では公開の無料TURN(ベストエフォート)を使います。混雑時は失敗することがあります。
- **確実にしたい場合**は自前のTURNを用意し、Vercel の環境変数に設定してください:
  `TURN_URLS`(カンマ区切り)/ `TURN_USERNAME` / `TURN_CREDENTIAL`
  → `GET /api/signal?want=ice` がこの設定を配り、クライアントが自動で使います(コード変更不要)。
- **同じWi-Fiに繋ぐ**のが最も成功率が高い回避策です。

- シグナリング(出会いの瞬間だけ)は `api/signal.js`(**Vercel KV**、ランキングと同じ環境変数)。**KV 未設定でも壊れない**:理由を明示したうえで 🤖 オフラインのデモ相方で体験できる。接続失敗時は原因別(サーバー未設定/部屋が無い/時間切れ/直通不可)に表示し、必ず次の一手を出す。

### 📲 PWA(ホーム画面に追加・オフライン動作)
Service Worker がアプリ本体をキャッシュするので、**電波が無くても起動して遊べる**。
アプリ本体は network-first(デプロイが確実に反映される)、アイコンは cache-first、
`/api/*` は**一切キャッシュしない**(対戦の合流・ランキングは常に最新)。
一度遊んだ人にだけ、タイトル画面で「ホーム画面に追加」を1回だけ控えめに案内する。

### 🎛 UI / 見やすさ
- **デザイントークンを `src/theme.js` に集約**。表示書体(丸ゴシック Baloo 2)は**ロゴと祝祭表現だけ**に限定し、UI・数値は幾何学サンセリフ(Outfit)で対比。**太い黒フチをやめて締まった影**に置き換え、枠線は整数座標にスナップして**にじみを解消**。
- 上部ボタンは **⚙ 設定(音・言語)** に集約 → タイトルの絵文字と重ならない。ゲーム中は一時停止/ホームのみを小さく半透明で表示。
- **背景の明度に応じた自動減光**を実装。パステル系の明るい面でも敵弾が背景に溶けない(弾は白い芯つき)。
- **起動スプラッシュ**(約2秒・タップでスキップ)からタイトルへ。
- 天気は**中央に都市名つき**で表示。天気の役割を明記(→ ルールは全モードに影響 / テーマ生成はエンドレスAI)。

## 🚀 デプロイ(Vercel + Gemini)
AIステージ生成のAPIキーはサーバー側に隠します(静的HTMLに埋め込むと露出するため)。

1. このリポジトリを Vercel にインポート。
2. **Environment Variables** に以下を登録:
   - `GEMINI_API_KEY` — [Google AI Studio](https://aistudio.google.com/app/apikey) の無料キー(AIステージ生成 `/api/ai-stage`)。
   - **ランキングを使う場合**: Vercel の **Storage → KV(Upstash Redis)** を作成しプロジェクトに接続すると、`KV_REST_API_URL` と `KV_REST_API_TOKEN` が自動で入ります(ランキング `/api/score`)。
3. デプロイ。`api/` 配下が自動でサーバーレス関数として動きます。

**フォールバック:** キー/KV 未設定・GitHub Pages 等の純静的ホスティングでも、AIステージは**端末内の手続き生成**に、ランキングは**非表示**に自動フォールバックし、ゲーム本体は完全に動作します。

### 🔔 まだ実装していない拡張(任意)
- **プッシュ通知でストリーク催促** — 本格対応には Service Worker + Web Push(VAPID鍵)+ Vercel Cron が必要。iOSはホーム画面追加(PWA)時のみ許可。現状は「アプリを開いた時のタイトル催促」で軽量に対応。要望あれば追加します。

### 使っている公開API(おすすめ)
リクエストのあった「一番簡単でメイクセンスな公開API」について:
- **天気: [Open-Meteo](https://open-meteo.com/)** — キー不要・無料・CORS対応。「現実のデータでゲームをダイナミックに変える」に最適で、実装が最も簡単。本作の AI World Engine に採用。
- **LLM: Gemini(Google AI Studio)** — 無料枠が大きく、公開ゲームで誰が何回遊んでも課金されにくい。JSON構造化出力対応でステージ生成に十分な品質。Vercel の環境変数にキーを1つ置くだけ。

(株価API等も候補ですが、天気=気分/世界観、LLM=無限の多様性、が最も「意味のある」使い方でした。)
