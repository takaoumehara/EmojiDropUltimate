# 🚀 EMOJI DROP ULTIMATE

方向がガラッと変わる絵文字シューティングゲーム。ツインビーにインスパイアされた、スマホ/デスクトップ両対応のブラウザゲームです。`index.html` 1ファイルだけで動作します(ビルド不要・依存CDNなし)。

**▶ 遊び方: `index.html` をブラウザで開くだけ**(GitHub Pages でもそのまま動きます)

### 🤖 3つのAIシステム
1. **AI World Engine(リアル天気連動)** — [Open-Meteo API](https://open-meteo.com/)(APIキー不要)で現在地(位置情報拒否時は東京)の天気を取得し、ゲームルールを書き換えます:
   - ⛈️ 雷雨 → ゲーム内に本物の落雷が落ちて敵を焼く
   - ❄️ 雪/🥶 氷点下 → 敵が減速+雪エフェクト
   - 🌧️ 雨 → 敵が活性化+雨エフェクト
   - 🌫️ 霧 → 視界不良(スコア+25%)
   - 💨 強風 → 弾やベルが風に流される
   - 🌙 夜 → ナイトモード配色(スコア+20%)
   - オフライン時は標準モードに自動フォールバック
2. **AIディレクター(動的難易度調整)** — 命中率・撃破ペース・被弾を常時観測してスキルを推定し、敵の湧き・射撃頻度・支援ベルの量をリアルタイム調整。調整時は画面に通知が出ます。
3. **学習するボス** — プレイヤーの移動速度と「よく居る場所」(位置ヒストグラム)を学習し、フェーズが進むほど偏差撃ち・置き撃ちしてきます(🧠マークが思考の合図)。

### 🔔 ツインビー風ベルシステム
ベルを撃つと色が変わる: ⚪スコア → 🔵スピード → 🔴パワー → 🟣オプション(分身) → 🟡シールド → 🟢ボム
