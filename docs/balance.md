# キャラの釣り合いと、開放のしかた

> 2026-08-19。「⚡ を使ったけど、とにかく強すぎる」「キャラは徐々に増えるようにしたい。
> でも後から手に入るのが強いとチートになるから、どれを使っても難易度は変わらないで、
> 特性だけが違う感じに」——この2つに同時に答えるための記録。

## 1. いちばん難しかったところ

**「進むと新しいものが手に入る」と「どれを使っても難易度は同じ」は、放っておくと矛盾する。**
ふつうのゲームは前者を「後のほうが強い」で実現していて、それをやると
進めた人だけゲームが簡単になる。それは腕前ではないので、遊びとしては壊れている。

ここでの答えはひとつだけ:

> **後から開くキャラは、強くない。派手で、扱いが難しい。**

増えるのは火力ではなく **選択肢と表現** で、代わりに **言うことを聞かなくなる**。
最初の3体はまっすぐ飛ぶ。最後に開く 🦍 は一番重い一撃を持っているが、
バナナは弧を描くので狙った所へは飛ばず、投げ直すのに一番時間がかかる。

これは気持ちの問題ではなく、**数字で縛れる**ようにしてある(§3)。

## 2. 開放のしかた

| | |
|---|---|
| 通貨 | **通算で制覇したステージ数**(`Save.stagesCleared()`) |
| 最初 | **3体**(🛩️ ファイター / 🐄 ウシ / 🐱 ネコ) |
| 増え方 | 1ステージ制覇ごとに1体 |
| 全部そろう | 13面クリア = **2章の途中** |

- 同じ面を何度クリアしても1回しか進まない。1面を往復するだけで16体そろってしまうため。
- **CHARS の並び順 = 開放順**。順番と `need` が食い違ったらテストが落ちる。
- 開放より前から遊んでいた人は、到達ステージと突破した章から数え直す。
  さらに **そのとき使っていたキャラは必ず残す** —— 昨日まで 🦍 で遊んでいた人の画面から
  🦍 が消えるのは、新しい仕組みの説明ではなく没収に見える。
- 鍵つきのキャラも **一覧にもカードにも出す**。中身も全部見せる。
  隠すと「何が待っているか」が分からず、続きを遊ぶ理由にならない。
  隠しているのは選ぶ権利だけで、情報ではない。

## 3. 「どれを使っても難易度は同じ」を機械で縛る

### 3-1. なぜ棒グラフでは足りなかったか

カードには5本の棒(ひとげき・れんしゃ・たまのはやさ・ねらい・みのこなし)が出ている。
これは1本ずつしか見えないので、**1本を伸ばして別の1本を削る調整をしていると、
全体では強くなっていても誰も気づけない**。実際、以前のテストは
`dmg ÷ fire` だけを 2.45 倍以内で縛っていて、⚡ はそこを素通りしていた。
⚡ の dmg も fire も平凡で、跳ね上がっていたのは **その式に出てこない項** だった。

### 3-2. 実効火力(`powerScore`)

`src/config.js` に置いた掛け算1本。ファイターが 1.00 になるようにしてある。

```
powerScore = dmg × (1/fire) × aim × girth × reach × multi × util × swift
```

| 項 | 式 | 何を値段として付けているか |
|---|---|---|
| `dmg × 1/fire` | — | 1発の重さ × 毎秒の発射回数 |
| `aim` | `0.45 + acc×0.55` | 曲がる弾は狙った所へ行かない |
| `girth` | `(size/4)^0.4` | 太い弾は雑な狙いでも当たる |
| `reach` | `0.38 + range×0.62` | 近距離キャラは敵に寄る = 死ぬ危険を払っている |
| `multi` | `1 + pierce×acc×0.34×(0.62+bspeed×0.38)` | 貫通。**狙えない弾の貫通は安く、速い弾の貫通は高い** |
| `util` | `1 + 鈍化0.09 + 横広がり0.11` | おまけ。小さいが0ではない |
| `swift` | `0.86 + bspeed×0.14` | 弾速。効きは弱め(主目的は読みやすさ) |

いま16体は **1.011 倍の幅**(±1%)に収まっている。テストは 1.15 倍で落とす。

### 3-3. 順番と強さが相関しないこと

実効火力が揃っているだけでは足りない。「前半8体の平均」と「後半8体の平均」が
4% 以上ずれたらテストが落ちる。これが **「後から開くキャラが強い = チート」を禁止する行** 。

### 3-4. 残してあるゆるい歯止め

`dmg/fire` の開きは 3.2 倍で見ている。これは釣り合いを見る指標ではなく、
「数字そのものが暴走していないか」だけの歯止め。本命は `powerScore` のほう。

## 4. ⚡ カミナリに何が起きていたか

原因は2つあって、**どちらもカードにも棒グラフにも出ていなかった**。

### 4-1. 貫通が無制限だった

`pierce: 1` は「1体抜ける」ではなく「**永久に消えない**」という意味だった。
⚡ は狙いが 1.00(まっすぐ)・弾速が全キャラ最速(2.1倍)なので、
一列に並んだ敵に対して **1発で列ごと消せた**。他の15体と同じゲームを遊んでいない。

**直し方**: `pierce` を「何体まで当てられるか」の予算に変えた。
無制限は作らない(テストで 0〜4 に縛ってある)。

| | 前 | いま |
|---|---|---|
| ⚡ カミナリ | 無制限 | **2体** |
| 🦄 ユニコーン | 無制限 | 2体 |
| 🧞 ランプの精 | 無制限 | 2体 |
| 🌲 ツリー | 無制限 | 3体(狙って当てられないので多め) |
| 🪃 ブーメラン(ベル) | 無制限 | 2体 |

### 4-2. ボスを毎フレーム削っていた ← こちらが本命

貫通弾はボスに当たっても消えなかったので、**ボスの体に重なっているあいだ
毎フレーム `damageBoss` が走っていた**。⚡ の弾は 882px/s、ボスの当たり判定は
半径45px 前後なので、1発が**5〜6発ぶん**入っていた。

**直し方**: 1発の弾がボスに入れられるのは1回だけ(`b.bossHit`)。

この2つを直したうえで、⚡ には
**一番速い弾**(2.1倍)と **一番長い溜め**(0.6秒級)を持たせている。
抜けるのは2体、線は自分で通す —— それが ⚡ のクセ。

### 4-3. ついでに見つかった同種のもの

🧞 の必殺技「ねがいごと」の当たり札(4分の1)が
散らした敵40体を **全部** 消せていた。1.9倍 → 1.25倍。
当たり札であって、押しただけで終わるボタンではない。

## 5. 数字を触るときの手順

1. `src/config.js` の `CHARS` を編集する
2. `node --test test/config.test.js test/balance.test.js` を走らせる
3. 実効火力が 1.15 倍を超えたら、**その子の `fire`(連射)で払わせる**のが基本。
   `fire` は間隔の倍率なので、大きいほど遅い。
4. カードの文言(`tag` / `lore`)が数字と食い違っていないか読み直す。
   **カードが嘘をつくのが、数字が偏ることより悪い。**

守っている不変条件(テストが縛る):

- 🐄 ウシは連射が最速。🐱 ネコは一番身軽。⚡ は弾が最速。🦍 は一撃が最重。
- 誰も誰かに全部の軸で勝っていない。
- 全員がどこかの軸で先頭に近い(平均だけのキャラを作らない)。
- 1トリガー1発から始まる(押しただけで強い状態を作らない)。

## 6. やらなかったこと

| 案 | 落とした理由 |
|---|---|
| 後半のキャラを本当に少し強くする | これが「チートになる」と言われた当のもの。1%でも入れたら、次の調整で必ず広がる |
| 鍵つきのキャラを一覧から隠す | 何が待っているか分からないと、続きを遊ぶ理由が消える。隠すのは選ぶ権利だけにした |
| 開放をスコアや撃破数で買わせる | 稼ぎ直しができてしまい、上手い人ではなく長く遊んだ人が有利になる |
| ⚡ の弾速を落とす | ⚡ の正体は速さなので、そこを削ると別のキャラになる。貫通の上限で払わせた |
| 全体の連射(300ms)を上げて重いキャラを楽にする | 難易度そのものを動かすことになる。頼まれたのはキャラ間の釣り合い |
