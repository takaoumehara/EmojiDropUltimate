# ミッションと章 — 何をどう決めたか

> 2026-07-30。判断の記録。実装は `src/story.js` / `src/aistage.js` / `test/story.test.js`。

## 1. 出発点にあった事実

**「6面終わったら違う6面が始まる」は前から動いていた。**
`Save.chapter()` と `chapterStages(n)` がそれで、第1章は手書きの6面、
第2章以降はテーマをシャッフルした生成6面、難度は章ごとに上がる。

**なのに一言も伝えていなかった。** タイトルには「第1章 ・ 世界 0/6 制覇」とだけ
出ていて、なぜ戦うのかも、6面の先に何があるのかも、どこにも書いていない。
足りなかったのは仕組みではなく **意味** のほう。

## 2. 決めたこと

| 論点 | 決定 | 理由 |
|---|---|---|
| 3章で終わり? 無限? | **手書き3章 + そのあと生成で無限** | 3章で切ると「終わらない」という一番の強みを自分で捨てる。逆に文章を全部機械に作らせると、外れた1本が世界観を壊す。骨格を手で見せてから同じ型で流す |
| エンドレスは残す? | **残す** | 「毎回ちがう面をさくっと」はストーリーでは満たせない(1面目から始まるので)。ただし入口の言葉を変えた |
| 6面クリアで終わり? | **7面目に章のボスを足す** | 6面で静かに次章へ入れ替わるだけでは、区切りが起きたことに気づけない |
| 最後のボスは何者か | **倒した6体が戻ってきて1つになる** | 絵で一番わかりやすい大詰め。ボスの仕組みをそのまま流用できる |

## 3. 通した比喩 — ショー

この世界はエモジの旅まわりの見世物で、**1章 = ひとつのショー**。
ショーが終われば次のショーが来る。第3章の最後に出るのは座長本人。

- 第1章「さらわれたなかま」 — 6人が6つの世界に連れ去られた → 🌀シックス
- 第2章「ぬすまれたベル」 — 音が盗まれ、幕が上がらない → 🔇サイレンス
- 第3章「さいごのショー」 — 仕組んでいたのは座長だった → 🎪リングマスター
- 第4章以降 — 「何を(6種)× 誰が(6種)」の組み合わせ。決定論なので、
  同じ章はいつ誰が見ても同じ話になる

## 4. どこに何が出るか

| 場所 | 出るもの |
|---|---|
| はじめて遊ぶとき | オープニング4コマ(絵1つ + 1行)。待てば進む・タップでも進む |
| 二度目以降 | 出ない。**出続けると「早く遊ばせろ」になる** |
| タイトルの 📖 | いつでも見返せる。見終わってもタイトルに戻るだけ |
| 面のはじまり | 「👑クラウドキング から 🐣 をすくえ」の1行 |
| タイトルのマップ | **いま挑んでいる章の7面**。最後の枠は章のボス(色を変える) |
| スタートボタン | ミッション名。「スタート」だけでは目的が伝わらない |
| 章を制覇した瞬間 | 幕が上がって「つぎのショーが はじまる」→ 次章の題とあらすじ |

## 5. 実装で踏んだ穴

- **`Save.clearedCount()` が6ビットしか数えていなかった。** 1章を7面にした瞬間、
  制覇の判定が永久に立たなくなる。`CHAPTER_LEN = 7` を置いて両方から参照する
- **`normalizeStage()` が dur を60秒に揃えてしまう。** 決着の1面は34秒にしたいので、
  正規化のあとで戻す
- **タイトルのマップが `STAGES` 決め打ち。** 第2章以降は実際に遊ぶ面と違う絵が
  出ていた(前からあったずれ)。いまの章の面から取る
- **「つぎのショー」を勝利画面に半透明で重ねたら、両方が透けて読めなくなった。**
  重ねるのではなく順番に見せる
- **オープニングを検査する側の罠**: コマは自動で進むので、テストから手でも
  進めると二重に消費されて、撮る前に終わる

## 6. まだやっていないこと

- 助けたなかま(🐣🐥…)を**タイトルや面のあいだに並べて見せる**。いまは
  ミッション文の中にしか出ていないので、集めている実感が薄い
- 章のあらすじを**共闘でも**出す(いまはストーリー単独のみ)
- 手書き章の音(章ごとのテーマ曲)
