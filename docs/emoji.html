このゲームが使っている文字、全部

敵もボスも背景もベルも、画像ではなく文字です。ここに出ているのは全部、いまあなたが見ている端末のフォントが描いた字形。下の一覧はソースコードから自動生成しているので、ゲームの中身と必ず一致します。

Q. どのシリーズの絵文字?

どのシリーズでもありません

絵文字の画像は1枚も同梱していません。ctx.fillText("🐙", x, y) と、ただの文字として描いているだけです。だから絵柄を決めているのはあなたの端末です。

iPhone・Mac → Apple Color Emoji ／ Android・ChromeOS → Noto Color Emoji ／ Windows → Segoe UI Emoji。同じコードでも端末ごとに違う絵が出ます。ライセンス上も、同梱していないので配布物に他社の絵は一切入っていません。

Q. 本当に全部絵文字?

ほぼ全部。例外が2種類あります

敵・ボス・背景・ステージ看板・自機キャラは全部、本物の Unicode 絵文字です。

例外1: 3文字(⚠︎ ⚙︎ ▶︎)は、わざと白黒に固定してあります。赤い「WARNING」の中で警告記号だけ黄色くなると意図が壊れるためです。
例外2: 自機の戦闘機・弾・ボスの本体・星・破片は絵文字ではなく、Canvas で描いた図形です。ページ下部の表にまとめました。
