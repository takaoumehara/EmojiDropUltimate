## この装置に測れないこと

| 測れる | 測れない |
|---|---|
| 詰みが無い / 空白が無い / 例外が出ない | 楽しいかどうか |
| 突破率・所要時間・命中率・死亡数 | 二度目を自分から始めるか |
| キャラ間の実測の開き | 難易度が「気持ちいい」か |
| 札が全部出るか | 人に見せたくなるか |

**面白さは測れない。** ここで上がるのは床であって天井ではない。
`docs/store-readiness.md` が書いているとおり、本当の関門は
「家庭の外の人が5人以上遊び、2回目を自分から始めるか」で、そこはコードでは動かない。
