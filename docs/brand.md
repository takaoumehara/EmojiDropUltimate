## 1. 売り — 何が本当の差別化か

### 1-1. 候補を全部並べて、順位を付ける

`README.md` は現在15個ほどの機能を並べている。順位が付いていないので、
読み手は**どれが芯か判定できない**。実際の強さは次のとおり。

| # | 主張 | 初見の人を連れてくる力 | 真似のしにくさ | 判定 |
|---|---|:---:|:---:|---|
| 1 | **ステージごとに進行方向が変わる（上/右/下/左）** | **高** | **高** | ★ これが売り |
| 2 | インストール不要・URL 1本・オフラインで動く | 高 | 中 | ○ 第二の柱。ただし §1-3 の注意 |
| 3 | 絵文字を見た瞬間に何が飛ぶか分かる（🦍→🍌） | 中 | 中 | ○ 説明書が要らない設計 |
| 4 | ボス終盤の6枚抽選（何も起きない回がある） | 低 | **高** | △ 深さ。2回目以降に効く |
| 5 | きずな（2人でしか成立しない攻撃） | 低 | 中 | △ 深さ。協力の存在理由 |
| 6 | リアル天気連動 | 低 | 中 | △ 「へえ」であって「やりたい」ではない |
| 7 | AIステージ生成 | **低** | **低** | ✗ 2026年には差別化にならない |
| 8 | 学習するボス / AIディレクター | 低 | 低 | ✗ 内部品質。売り文句にはならない |
| 9 | デイリー・ランキング・ストリーク・共有 | 低 | 低 | ✗ 定着の仕掛けであって集客ではない |

### 1-2. なぜ 1 が唯一の売りなのか

- **3秒のGIFで伝わる。** 画面そのものが回る。文章の説明が要らない。
- **他のシューティングには構造的に真似しにくい。** 縦シューは縦、横シューは横で
  UI・当たり判定・弾幕設計・指の置き場所が全部その向きに固定されている。
  後から「向きが変わる」を足すのは作り直しに近い。
- **自分でもそう書いている。** `docs/product-idea.md` の最高得点札 `turn`(38点) は
  この芯をボス戦の最中にやる一手で、「他のシューティングには真似のしようがない」と
  評価されている。**芯は既に自分で特定できていて、名前と説明文だけが追いついていない。**

### 1-3. いま「売り」として言ってはいけないもの

| 言いたくなること | なぜ言えないか |
|---|---|
| **「最大4人」** | 公開状態は **2人まで**。中継サーバーが立っていない（`docs/status.md` §1）。書けば嘘になる |
| **「面白い」** | 第三者検証がゼロ。自己評価でも「面白さの証明 45点」（`docs/store-readiness.md`） |
| **「AI が〜」** | 2026年に AI は差別化ではなく雑音。しかも芯（方向）の前に置くと芯が埋もれる |

### 1-4. いまの説明文が犯している間違い

`manifest.webmanifest` の description:

> 方向がガラッと変わる絵文字シューティング。**リアル天気連動AI・学習ボス・AIステージ無限生成。**

前半（芯）が1文、後半（枝葉のAI3連発）が1文。**文字数がほぼ半々**なので、
読み手には同じ重みに見える。og:description も同じ構造。

**提案（改名の有無に関わらず、今日変えられる）:**

```
ja: 面が変わると、世界の向きが変わる。上・右・下・左へ進む絵文字シューティング。
    インストール不要、URLを開くだけ。オフラインでも動く。
en: Every stage turns the world. A shooter that runs up, right, down and left.
    No install. Just a URL. Works offline.
```

AI・天気・生成は**本文の下の方**へ。消す必要はない。順番を直すだけ。

### 1-5. もう一つの売り — こちらは相手が違う

`docs/brief.md` §6 が自分で書いているとおり、**本命はポートフォリオ**。
これはプレイヤー向けの売りと**混ぜてはいけない**。相手も刺さる点も別物。

| | プレイヤー向け | 技術者・採用側向け |
|---|---|---|
| 売り | 世界の向きが変わる | **依存ゼロ・ビルド工程なしで、これだけ動く** |
| 証拠 | 3秒のGIF | 約10,600行のJS / 192件のテスト / WebRTC P2P + ホスト権威同期 / Web Audio 合成音楽（先読みスケジューラ・ヒステリシス）/ 自前QRエンコーダ / 依存ゼロの中継サーバー / ホスト引き継ぎ |
| どこに置くか | ゲームの画面・OGP・SNS | README上部・ケーススタディ記事 |

技術者向けの売りは、**「作れる」ではなく「足さずに作れる」**が刺さる点。
`package.json` が無いこと自体が主張になる。README の冒頭にこれが無いのは損。

## 2. 名前 — いまの名前の何が問題か

### `EMOJI DROP ULTIMATE`

| 問題 | 具体 | 深刻度 |
|---|---|---|
| **`DROP` が嘘** | 落ちてくるのは6面中1面（③フリーフォール）だけ。実際は 上・右・下・左・上・上。**名前が唯一の売りを否定している** | **致命的** |
| `ULTIMATE` が情報ゼロ | 続編でもないのに ULTIMATE。無料の個人作品では「盛っている」信号として読まれる | 中 |
| `EMOJI` で検索が死ぬ | 絵文字キーボード・素材サイト・スタンプアプリの海。App Store / Google Play / GitHub のどこでも埋もれる | **高** |
| 一般名詞の集合 | 商標として守れない（逆に、取られる心配も無い代わりに自分のものにもならない） | 中 |

**一番大きいのは1行目。** 売りを言語化した結果、名前がそれと逆を言っていることが分かった。

### 改名するなら、いまである理由

| | いま | 遊ばれ始めた後 |
|---|---|---|
| 外部ユーザー | **0人**（`docs/status.md`：家庭外で一度も遊ばれていない） | 混乱する人がいる |
| 貼られたリンク | ほぼ無い | 死ぬ |
| ストアID | まだ取っていない | **変更不可** |
| セーブキー | `edu_save`（`src/save.js:14`）。移行の必要なし | 移行コードが要る |

**改名コストが二度とこれより下がらない。** 逆に言えば、いま決めなくても
「遊ばせる前に決める」だけは守るべき。

## 3. 名前の候補

判定基準（先に決めた）:
1. **芯（方向が変わる）を言っているか**
2. **検索して自分が1位を取れるか**（日本語圏・英語圏の両方）
3. 子供が声に出せるか / 日英で同じに読めるか
4. 絵文字1つで表せるか
5. アイコンの下に収まる長さか（〜8文字）

### 推し ①  `TURNSHOW` 🌀 ／ ターンショー

| 基準 | 判定 |
|---|---|
| 芯 | ○ `turn` が芯そのもの。`docs/product-idea.md` の最高得点札の名前と一致 |
| 検索 | **○ 空いている**（App Store / Google Play / Steam に同名見当たらず） |
| 発音 | ○ 日英で同じ。4音（ター・ン・ショ・ー） |
| 絵文字 | ○ 🌀（回る）と 🎪（ショー）の両方が使える |
| 長さ | ○ 8文字 |

**さらに強い理由**: `docs/story.md` が既に「1章 = ひとつのショー / 旅まわりの見世物 /
第3章の黒幕は座長」という比喩で世界観を組んでいる。**`TURNSHOW` は新しい上着ではなく、
既にある骨格の名前**になる。ミッション表示・幕・「つぎのショーが はじまる」と全部繋がる。

**弱点（正直に）**: 英語圏で `turn` は「ターン制」を連想させうる。
🌀 とタグライン（"Every stage turns the world."）で打ち消す必要がある。

### 次点 ②  `KURUN` 🌀 ／ くるん

- **芯を音で言っている。** 「向きがくるんと変わる」。説明が要らない。
- 2音節・子供が一発で言える・日英で発音が同じ。
- 意味を持たない token なので、記憶に残れば完全に自分のものになる（Balatro / Suika 型）。
- **弱点1: 日本の検索1位は取れない。** 靴ブランドの [kurun TOKYO / kurun.jp](https://kurun.jp/pages/company)（2019〜）が先着。
  区分が違う（第25類 履物 vs 第9/41類 ゲーム）ので**商標としては共存できる可能性が高い**が、
  「kurun」で検索したとき日本では靴が先に出る。**主戦場が日本ならここは実害。**
- 弱点2: Steam に [KURU](https://store.steampowered.com/app/3067780/KURU/) がある（別ジャンル、名前は1文字違い）。
- 弱点3: 英語圏には意味が無い → タグライン必須。

### 第三の道 ③  変えない（`EMOJI DROP ULTIMATE` のまま）

**これも正当な選択。** 理由:

- 名前より先に、**第三者に遊ばせる（`docs/status.md` §3-B）**が止まっている。
  名前を磨いても、誰も遊んでいない状態は1ミリも動かない。
- 改名は半日。**5人に遊ばせるのも半日。順番としては後者が先。**
- ただし **`DROP` の嘘は説明文で埋められる**ので、
  改名しないなら §1-4 の description 差し替えだけは今日やる価値がある。

**推奨の順番**: ①説明文を直す（今日・1時間）→ ②第三者に遊ばせる → ③反応を見てから改名を決める。
改名の判断材料は「初見の人が名前から何を期待したか」なので、遊ばせる前に決める必要は無い。

### 却下した案と、その理由

| 案 | 却下理由 |
|---|---|
| `VEER` | Steam に [Veer](https://store.steampowered.com/app/405530/Veer/)(2019, パズル)・[Dark Veer](https://store.steampowered.com/app/1149700/Dark_Veer/)・[Reborn To VeeR](https://store.steampowered.com/app/2280590/Reborn_To_VeeR/)。混み合いすぎ |
| `SIXAXIS` 系 | ソニーの登録商標。検討の余地なし |
| `TURNABOUT` | 逆転裁判の英題シリーズ（[Turnabout](https://en.wikipedia.org/wiki/Turnabout_(game_show)) 他） |
| `ALLWAYS` | 「全方向」と `always` の掛け言葉として良いが、検索で `always` に飲まれて消える |
| `SIXWAY` / `SIXTURN` | **嘘になる**。6ステージだが方向は4種（上右下左） |
| `TURNTABLE` | DJアプリ・音楽サービスに食われている |
| `PIVOT` | ビジネス用語に食われている |
| `EMOJI 〜` を残す全案 | 検索で死ぬという最大の問題が残るので、改名する意味が消える |

## 5. VVA Matrix 座標

既存の実装（`src/theme.js`）から逆算した、いまの実態。

| 軸 | 座標 | 根拠 |
|---|---|---|
| **Tone Register** | **TR-3 Playful Inventive** | 絵文字が主役。ミッション文が「👑クラウドキング から 🐣 をすくえ」 |
| **Visual Purity** | **VD-2 Engineered Precision** | `theme.js` の方針そのまま:「かわいい」は絵文字が担当、UIは高コントラストで支える。整数座標スナップ・黒フチ不使用 |
| **User Stance** | **UA-3 Empathetic Guide** | 追い詰められたときだけベルが来る／死んだ地点から4.5秒巻き戻す／保存できない環境でも落ちない |
| **Sensory Tempo** | **ST-3 Rhythmic Fluid** | 緊張度でBGMのレイヤーが増減、テーマ色がなめらかに補間 |

**この組み合わせの意味**: 見た目は子供向け、作りは大人向け。
**そのギャップ自体がこの製品の性格**なので、どちらかに寄せてはいけない。

### 3つの形容詞

**くるくる変わる（Turning） / 説明が要らない（Self-evident） / 足していない（Dependency-free）**

### トーン・オブ・ボイス

- **数字で言う。** 「すごく速い」ではなく「20〜80ms」。既存の docs が全部これで書かれている
- **できていないことを先に書く。** `docs/status.md` の「4人は遊べない」がお手本
- **煽らない。** `ULTIMATE` `最強` `革命` を使わない
- **絵文字は意味を持つときだけ。** 装飾で使うと、ゲーム内で絵文字が持つ意味が薄まる
