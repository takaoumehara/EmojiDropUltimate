# EMOJI DROP ULTIMATE — 設計ブリーフ / 意思決定の記録

> このファイルは「なぜ今この形なのか」を残すためのもの。
> 会話は消えるが、判断の理由が残っていれば別の人(別のAI)が続きを作れる。

## 1. これは何か

方向がステージ毎に変わる絵文字シューティング。Web(Vercel)配信、
**ビルド工程なし・外部ライブラリなし・オフライン動作**が制約であり売り。

## 2. 破ってはいけない原則

| 原則 | 理由 |
|---|---|
| **外部依存を足さない** | 「URL 1本で即遊べる」が最大の強み。CDN/フレームワークを入れた瞬間に、オフライン動作と起動速度という差別化が消える |
| **サーバーはゲーム中の経路に入れない** | シューティングは弾を避けるゲーム。往復遅延は体験を壊す。サーバーは「出会う瞬間」だけに使う |
| **キーが無くても遊べる** | Gemini・KV・TURN が全部無くても、ゲームは完全に成立する。機能は劣化するが壊れない |
| **絵文字の役割を混ぜない** | プレイヤーが選べるキャラの絵文字は、敵やボスに**絶対**使わない。混ざると「自分がどれか」が壊れる |
| **足すより削る** | 機能過多で一度「ごちゃごちゃ」に陥っている。迷ったら削る |

## 3. 主要な設計判断

### 3-1. ふたりでプレイ = WebRTC P2P + ホスト権威
- **P2P直結**(遅延20〜80ms)。シグナリング(`/api/signal`, Upstash)は SDP 交換のみ、5分で消滅。
- **世界の正はホスト**。敵・弾・ベル・ボスはホストだけが計算し、約15Hzでスナップショット配信。
  ゲストは補間して映し、自機と自分の弾だけローカルに動かす(=操作遅延ゼロ)。
- **なぜ**: 各端末で乱数・AI難易度調整・天気を独立に回すと必ずズレる(実際にズレた)。
- **既知の弱点**: ホストが1人のプレイヤー端末なので、ホストが落ちると世界が消える。
  3〜4人や遠隔の安定運用に進むなら、中立の常駐サーバーへ移すのが正攻法(ゲーム側の同期ロジックはそのまま流用可)。
- **残機はチーム共有**。片方だけ取り残される状態を構造的に作らないため。

### 3-2. 章(チャプター)構成
6ステージ=1章。制覇→勝利演出→次章が開く。第1章は手書き、第2章以降はテーマを
章ごとに決定論シャッフルして6つ(重複なし)生成し、章が進むほど強くなる。
- **なぜ**: 6つだけだと短すぎ、無限だと終わりが無くて疲れる。「区切りのある無限」にした。

### 3-3. 集中モード
その場に踏みとどまると連射が上がり、移動が遅くなる。
- **なぜ**: スマホは指1本が移動で塞がるので、撃つボタンは足せない。
  既にできる「止まる」に意味を持たせ、**攻めるか避けるかの判断**を作った。

### 3-4b. 16体を「見た目だけの差」にしない
全員が別の飛び方をする。straight のままなのはファイター(入口)とウシ(素直な速射)の2体だけで、
それ以上増えたらテストが落ちる。
- 加速🚀 / 追尾🐾 / 貫通ビーム⚡ / 近距離🍕 / 育つ✨ / 失速💩 / 波打つ💧 / 引き寄せ🥖 /
  散る🥕 / 渦❄️ / 横流れ🍃 / 跳ね返り🦴 / 弧🍌 / 分裂🥚
- **強い癖には必ず埋め合わせ**を付ける(遅い・連射が落ちる・射程が短い)。素の火力の
  開きは2.45倍以内でテストが縛る。
- カードの見本線(`TRAJ_PREVIEW`)は実装と別物なので、片方だけ増やすとテストが落ちる。

### 3-4. キャラクター(16体)と、絵文字の住み分け
「その絵文字なら何を投げるか」で弾を決めている(🦍→🍌、🐄→🥛、🧑‍🍳→🥖)。
見た瞬間に何が飛ぶか分かるので、説明を読まなくていい。
- **絶対に守る**: キャラの絵文字を敵・ボスに使わない。**弾の絵文字も**敵・背景に使わない。
  ❄️ が「雪だるまの弾」かつ「氷結パレスの敵」だった状態は、撃っているのか撃たれて
  いるのか分からなくなる。両方ともテストで縛ってある。
- 性能差は `dmg`(1発の重さ)と `fire`(連射)の掛け算でほぼ揃え、違いは
  **当てやすさと取り回し**に出す。素の火力の開きが2.4倍を超えたらテストが落ちる。
- 自機の絵は 42px。当たり判定は `hitR = 7` 固定なので、絵を大きくしても不利にならない。

### 3-5. 手応えの作り方(子供に遊んでもらって分かったこと)
- **難度は「弾の数」で決まっていた**。弾速を落として読めるようにしたら、遅い弾が
  長く残って画面が自弾で埋まり、狙う必要が消えて逆に簡単になった(ウシで**画面に22発**)。
  結論: 弾速ではなく**連射**が難度のつまみ。速度は420に戻し、**連射をほぼ半分**に、
  集中モードの倍率も1.8倍→1.4倍に抑えた。実測でPW1は6〜11発。
- **弾は読める下限まで小さく**。18pxあれば 🍌🥛🥚🥖💧 は判別できる(実測)ので 19px に。
  輪で囲むのはやめて、進行方向の後ろに短い尾を引く。囲むと実寸より大きく感じるうえ、
  「飛んでいる物」ではなく「閉じ込められた玉」に見える。
- **自機を囲む輪の正体は集中モードの表示だった**。指を止めている間ずっと出るので、
  常時「丸で囲まれている」状態になっていた。溜まる間だけゲージとして一周させ、
  溜まりきったら上下の短い弧だけ残す。
- **ベルは「湧くもの」から「硬い敵を倒した見返り」へ**。時限湧きは大幅に間隔を空け、
  HP3以上の敵が9秒に1回まで落とす。実測で60秒あたり4.5個・画面上は最大2個。
- **ベルで撃つ方向が変わる**(ブーメラン/うしろ/よこ)。すべて時限なので居座らない。
  補助方向は主砲より少し速く・少し小さく撃って見分けを付ける。
- **ボスは必ず一度蘇る**。1面だけで起きて2面で起きないと「たまたま」に見えて驚きが
  台無しになるので、確率をやめて全ボスに。倒したと思わせる1.5秒の「間」は必須。
  蘇ると1.75倍・HP1.45倍になり、**予告なしの突進**(約1500px/s)を混ぜてくる。
- **追い詰められた時だけベルが来る**。ボス戦で丸腰のまま殴られ続けるのは「難しい」
  ではなく「詰み」。1ステージ2回まで、残機が危なければ LIFE から始まる色で出す。

### 3-6. カラー絵文字を Canvas に描くときの罠(2回踏んだ)
`fillText` でカラー絵文字を描くと、**fillStyle の「アルファ」が絵文字に掛かる**
(RGBは無視されるのに、アルファだけは効く)。直前に半透明の塗りやグラデーションを
使っていると、絵文字そのものが薄く滲んで「ぼやけた玉」になる。
- 実際に起きたこと: 弾の光背(放射グラデーション)を敷いた直後に `fillText` していたため、
  🍌 が中心から外へ向かって透明になり、バナナに見えなくなっていた。
  ボスはオーラ(alpha 0.2)、ベルは光背(alpha 0.33)が乗って同じ症状。
- 対策: 絵文字を描く直前は必ず `inkEmoji()` を通して不透明に戻す。
  自機だけは以前この症状を直していたのに、他の描画に横展開できていなかった。
- ついでに: 絵文字はビットマップなので、端数座標のまま描くと拡大縮小で滲む。
  弾は `Math.round(x * DPR) / DPR` で画素に載せている。
- **同系色の光背を敷かない**。🍌 に黄色い光背は図と地を潰す。最終的に光背も輪もやめ、
  進行方向の後ろへ引く短い尾だけにした。

### 3-7. 端末の「触れない縁」(iPhone)
`viewport-fit=cover` を入れた時点で W/H は画面いっぱいになる。HTML のボタンは
`env(safe-area-inset-*)` で逃がせるが、**キャンバスに描く HUD は自分で避けるしかない**。
- `env()` を CSS 変数(`--sat` 等)に落とし、`env.js` がそれを読んで `SAFE` に持つ。
  こうしておくと、Chromium のように `env()` を出さない環境でも変数を差し替えて検証できる。
- 縦位置は `vy(割合)` = セーフエリアの内側を 0〜1 とする座標で置く。`H * 0.968` の
  ような直書きは、ホームバーの下にハイスコアを押し込む。
- 自機の可動域も `SAFE` の内側。ホームバーの上に乗ると自分の指で隠れる。

### 3-8. 「つづき」は死んだところから
ステージ番号しか覚えていないと、毎回そのステージの頭に戻される。同じ道のりを
やり直させるのが一番続ける気を削ぐので、**ステージ内の進行度(時間・ウェーブ)**を
保存して再開する。
- ただし本当に同じ一瞬から戻すと、自分を殺した弾に突っ込むだけ。**4.5秒巻き戻す**。
- ボス戦で死んだ場合はボスの直前から(道中をもう一度歩かせない)。

### 3-9. 天気連動の効き方(混乱しやすいので明記)
- **ルール**(落雷・夜・風・敵速度・スコア倍率)は**全モード**に効く。
- **テーマ生成**に天気を使うのは**エンドレスAIのみ**。

### 3-10. 音
録音を再生せず、Web Audio で合成。テーマ毎の音色パレット + 緊張度で層が増減。
別プロジェクト(typespace)の生成音楽から移植したのは**技法だけ**で、思想は移植していない。
- 採用: コード生成リバーブ、非整数倍音の鐘、互いに素な周期による非反復、
  同一音集合の回転による安全な転調、拍グリッドへの量子化。
- **不採用**: 「不協和を作らない」原則。あちらは瞑想作品なので緊張が不要だが、
  シューティングは緊張と解放が快感の源なので、そのまま持ち込むと平坦になる。
- **先読みスケジューラ**: setTimeout は数ms揺れる。25ms ごとに 200ms 先までを
  AudioContext の絶対時刻で予約する方式に変えた。素人臭さの最大の原因は
  音色ではなくタイミングの揺れなので、ここが一番効いた。
- **ヒステリシス**: 緊張度でレイヤーを出し入れすると、閾値付近でパタパタする。
  上がる閾値と下がる閾値をずらして解決(0.30↑/0.20↓ 等)。
- 度数(スケール上の位置)で作曲しているので、和音がどう回っても調から外れない。
  外れる音は「ピンチ」の1音だけ、意図的に。
