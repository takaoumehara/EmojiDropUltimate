# いまどこまで動くのか / 何が残っているのか

> 2026-08-11 更新(v2.0 PARTY)。
> **「コードが書けている」と「遊べる」は別**なので、そこを分けて書く。
> 数字は実測、状態は実際のファイルを見て確認したもの。
> 版の一覧は [versions.md](./versions.md)。

## 1. 結論から

| | いま公開されている状態 | 必要なもの |
|---|---|---|
| ソロ | **遊べる** | — |
| ふたり | **遊べる**(端末どうしの直結) | — |
| **3〜4人** | **遊べる**(網目の直結・v2.0 から) | **サーバーは不要になった** |

### 何が変わったのか(v1.0 → v2.0)

かつてここには「3〜4人は遊べない。中継サーバーを立てる必要があり、
月額が発生するので止めてある」と書いてあった。**その前提が外れた。**

塞いでいたのは中継サーバーの不在そのものではなく、
**出会いの仕組み(`api/signal.js`)が2人ぶんの棚しか持っていなかったこと**だった。
直結は `RTCPeerConnection` を人数ぶん持てば網目になる。棚を組ごとに分け、
部屋(いま誰が居るか)を足したので、**サーバーを立てずに4人が繋がる**。
月額は今まで通りゼロ。

- 網目の実装 … `src/mesh.js`(検証は `test/mesh.test.js`)
- 部屋と組ごとの棚 … `api/signal.js`(検証は `test/signal.test.js`)
- ホストが抜けたときの後継 … `src/coop.js` の `electHost`

### 中継サーバーは消していない

`index.html:12` の `coop-relay` に URL を書けば、今まで通り中継が優先される。
網目で繋がらない組み合わせが実機で出たときの逃げ道として残してある
(→ [costs.md](./costs.md))。書かなければ網目だけで動く。

### 網目で新しく背負ったもの

| | 中身 |
|---|---|
| ホストの上り | 中継なら1通のワールド状態を、4人なら**3通**送る(≒100KB/秒)。上りの細い回線が最初に苦しくなる |
| 組ごとの独立 | 4人のうち**1組だけ**直通が張れないことがありうる。その人だけ入れない |
| 合図サーバーの回数 | ロビー中は3秒ごとに顔ぶれを見に行く(始まったら15秒間隔に落とす) |

## 2. 検証したこと / していないこと

| | 状態 |
|---|---|
| 自動テスト | **233件・全パス**(`node --test test/*.test.js`) |
| 1台のブラウザ4枚で4人プレイ | **確認済み**(位置・敵・残機が一致、ホスト引き継ぎも)。ただし中継経由での確認 |
| **網目(サーバー無し)での4人** | **自動テストのみ。実ブラウザではまだ** |
| 中継サーバーの負荷 | **確認済み**(50部屋/100接続で p95 1.63ms) |
| iPhone / Android の実機 | **未**(画面サイズの再現のみ) |
| **携帯回線をまたいだ4人** | **未。ここが一番の未知** |
| 家庭外の人に遊ばせる | **未。一度もやっていない** |

ブラウザ4枚は同じ1台の中の話で、遅延も回線品質も現実とは違う。
**「動いた」と言えるのは1台の中までで、外はまだ何も分かっていない。**

## 3. 残っていること(優先順)

### A. 4人で遊べると言い切るために残っていること
1. ~~中継サーバーを立てる(**お金の判断**)~~ → **不要になった**(v2.0 の網目)
2. ~~`index.html:12` に URL を書く~~ → **不要**(書けば中継が優先されるだけ)
3. **実機4台・携帯回線で確認。ここだけが残っている。**
   自動テストが通っているのは「段取りが正しい」ことの証明であって、
   4本の携帯回線をまたいで繋がる証明ではない

### B. これをやらないと出す意味がない
4. **家庭の外の人に5人以上遊ばせる。** 判定は「言われなくても2回目を始めるか」だけ。
   ここは**コードでは動かせない唯一の項目**で、ずっと止まっている。

### C. ストアに出すなら要る(コードではなく書類と画像)
5. プライバシーポリシーを**公開URL**に置く(本文は `docs/privacy.md` にある)
6. データセーフティ申告・年齢レーティング
7. アイコン各サイズ・スクリーンショット一式
8. サポート窓口

### D. 品質として足りていない
9. ~~ロビーで「誰が準備できたか」が見えない~~ → **済**(名前と✓を表示)
9b. ~~横に広い画面で盤面が広がりすぎ / 横持ちで文字が重なる~~ → **済**。
    盤面を「遊ぶ板」に固定して中央へ、UI の底上げを縦の短さで緩めた
    (`src/env.js`、判断の記録は [layout.md](./layout.md))
10. 色覚特性への配慮なし / 音量が ON・OFF のみ
11. 対応言語が日英2つ
12. 初回の遊び方の導入が短いテキストのみ

### E. 技術的な宿題
13. **サーバー側で世界を計算する**(`docs/multiplayer.md` の段3)。
    やると「ホストだけ遅延ゼロの不公平」「ホストが抜けると終わる」
    「ホストが改造すれば何でもできる」「人数の上限」が**まとめて消える**。未着手。
14. **中継の圧縮(permessage-deflate)。** 帯域が 1/3〜1/5 になる見込みで、
    そのまま月額に効く(→ [costs.md](./costs.md))
15. ホスト引き継ぎの瞬間に道中の敵が消える(意図的だが、より滑らかにできる)
16. ~~終盤で進行方向が変わる札~~ → **済**(6枚目の札として実装)
17. ~~「2人でも1人と変わらない」~~ → **済**。技16種・合体・**きずな**(`src/tether.js`)。
    きずなは「ひとりでは絶対に成立しない遊び」で、`test/tether.test.js` がそれを証明している。
18. ~~章の区切りが伝わっていない~~ → **済**。ミッション・オープニング・7面目の決着・
    「つぎのショー」(`src/story.js`、判断の記録は [story.md](./story.md))

## 4. 「書いたが繋がっていない」もの

**無くなった。** v2.0 で 3〜4人が既定の経路(網目)で動くようになったので、
「コードはあるのに既定で動かない」機能はもう無い。

中継サーバーは**任意の代替経路**として残っている。これは「繋がっていない」
のではなく、「網目で足りるので既定では使わない」もの。

| | 場所 | 既定 | 使うには |
|---|---|---|---|
| 中継サーバー | `server/` + `index.html:12` | **オフ(網目を使う)** | サーバーを立てて URL を書く |

参考に、**環境変数が要る**機能(これらは Vercel 側の設定で既に動いている):

| 機能 | 要る設定 |
|---|---|
| ふたりでプレイの出会い | `UPSTASH_REDIS_REST_URL` / `_TOKEN` |
| 直結の補助(TURN) | `TURN_URLS` / `TURN_CREDENTIAL`(無くても既定で動く) |
| AIステージ生成 | `GEMINI_API_KEY` |
