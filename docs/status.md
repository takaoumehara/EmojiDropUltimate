# いまどこまで動くのか / 何が残っているのか

> 2026-07-29。**「コードが書けている」と「遊べる」は別**なので、そこを分けて書く。
> 数字は実測、状態は実際のファイルを見て確認したもの。

## 1. 結論から

| | いま公開されている状態 | 必要なもの |
|---|---|---|
| ソロ | **遊べる** | — |
| ふたり | **遊べる**(端末どうしの直結) | — |
| **3〜4人** | **遊べない** | 中継サーバーを立てて `index.html` に1行 |

**4人プレイのコードは書けていて、テストも通っている。**
動かないのは**サーバーがどこにも立っていない**から。

根拠は `index.html:12`:

```html
<meta name="coop-relay" content="">
```

ここが空だと `src/coop.js` の `makeTransport()` は中継を作らず、
直結(`RtcTransport`)だけを返す。直結は `RTCPeerConnection` を1本しか張らないので、
**相手はひとりまで**。つまり公開中のゲームは、いまも2人用のまま。

### 4人にするのに要る手順

| | やること | 手間 | お金 |
|---|---|---|---|
| 1 | `server/` をどこかに立てる(→ [costs.md](./costs.md)) | 30分程度 | **月$2〜7から** |
| 2 | TLS を付ける(`wss://` でないとHTTPSのページから繋げない) | 上に含む | 同上 |
| 3 | `index.html:12` にその URL を書く | 1分 | 無料 |
| 4 | **実機4台・携帯回線で確かめる** | 半日 | 無料 |

1 と 2 はお金の判断なので、こちらでは踏み込まずに止めてある。

ブラウザ4枚は同じ1台の中の話で、遅延も回線品質も現実とは違う。
**「動いた」と言えるのは1台の中までで、外はまだ何も分かっていない。**

## 3. 残っていること(優先順)

### A. これをやらないと4人で遊べない
1. 中継サーバーを立てる(**お金の判断**)
2. `index.html:12` に URL を書く
3. 実機4台・携帯回線で確認

### B. これをやらないと出す意味がない
4. **家庭の外の人に5人以上遊ばせる。** 判定は「言われなくても2回目を始めるか」だけ。
   ここは**コードでは動かせない唯一の項目**で、ずっと止まっている。

## 4. 「書いたが繋がっていない」もの

いま現在、**コードはあるのに既定で動かない**のはこの1つだけ。

| | 場所 | 既定 | 動かすには |
|---|---|---|---|
| 中継サーバー | `server/` + `index.html:12` | **オフ** | サーバーを立てて URL を書く |

参考に、**環境変数が要る**機能(これらは Vercel 側の設定で既に動いている):

| 機能 | 要る設定 |
|---|---|
| ふたりでプレイの出会い | `UPSTASH_REDIS_REST_URL` / `_TOKEN` |
| 直結の補助(TURN) | `TURN_URLS` / `TURN_CREDENTIAL`(無くても既定で動く) |
| AIステージ生成 | `GEMINI_API_KEY` |
