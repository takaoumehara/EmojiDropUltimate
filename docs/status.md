## 1. 結論から

| | いま公開されている状態 | 必要なもの |
|---|---|---|
| ソロ | **遊べる** | — |
| ふたり | **遊べる**(端末どうしの直結) | — |
| **3〜4人** | **直結(P2P)で繋がるはず**(コード上は。実機未確認) | — |

**中継サーバーを別途立てなくても、3〜4人が繋がるようになった**
(2026-09-12)。ホストが最大3本の `RTCPeerConnection` を張る星型で、
ゲスト同士のぶんはホストが中継する。信号サーバー(`/api/signal`、Vercel KV)は
今まで通り「出会う瞬間のSDP交換」だけで、月々の追加費用は無い。

根拠は `src/coop.js` の `RtcHostTransport`(ホストが3枠ぶん張る)と
`RtcGuestTransport`(ゲストが空いている枠を1つ選ぶ)、
`api/signal.js`(枠ごとに別の鍵でSDPを預かる)。

ただし**このセッションからは実機・実際のKVを使って生きたハンドシェイクを
一度も試せていない**(→ 冒頭の 2026-09-12 追記)。テストで確かめたのは
「繋がった後、誰の位置を誰に流すか」までで、「実際に繋がるか」自体は
公開後に実機で確かめてほしい。

### 中継サーバーは、まだ意味がある(必須ではなく保険として)

直結(P2P)は、回線によっては(症状の重い NAT・一部の携帯回線など)
そもそも直通が張れないことがある。中継サーバーを立てておくと、
直結が失敗した相手だけ自動でそちらへ乗り換わる(`src/wstransport.js` の
`DualTransport`)。**やらなくても3〜4人は繋がる想定**なので、
これは「繋がる率をさらに上げたい場合」の追加投資。

| | やること | 手間 | お金 |
|---|---|---|---|
| 1 | `server/` をどこかに立てる(→ [costs.md](./costs.md)) | 30分程度 | **月$2〜7から** |
| 2 | TLS を付ける(`wss://` でないとHTTPSのページから繋げない) | 上に含む | 同上 |
| 3 | `index.html:12` にその URL を書く | 1分 | 無料 |
| 4 | **実機4台・携帯回線で確かめる** | 半日 | 無料 |

1 と 2 はお金の判断なので、こちらでは踏み込まずに止めてある。

## 2. 検証したこと / していないこと

| | 状態 |
|---|---|
| 自動テスト | **235件・全パス**(`node --test test/*.test.js`) |
| 1台のブラウザ4枚で4人プレイ(中継サーバー経由) | **確認済み**(位置・敵・残機が一致、ホスト引き継ぎも) |
| 中継サーバーの負荷 | **確認済み**(50部屋/100接続で p95 1.63ms) |
| ホストの星型中継(誰の位置を誰に流すか) | **確認済み**(`test/coop-mesh.test.js`。ただし擬似DataChannelでの検証 — 下記) |
| **直結(P2P)で3〜4人が実際に繋がるか** | **未。生きた WebRTC ハンドシェイクを一度も試せていない** |
| iPhone / Android の実機 | **未**(画面サイズの再現のみ) |
| **携帯回線をまたいだ4人** | **未。ここが一番の未知** |
| 家庭外の人に遊ばせる | **未。一度もやっていない** |

`test/coop-mesh.test.js` は `RTCDataChannel` の代わりに `send()`/`onmessage`
だけを持つ入れ物で確かめている。**「繋がった後の中継が正しいか」の確認で、
「実際に繋がるか」自体の確認ではない** —— それには実際のブラウザ2台以上と
生きた信号サーバー(Vercel KV)が要り、このセッションには無い。

ブラウザ4枚は同じ1台の中の話で、遅延も回線品質も現実とは違う。
**「動いた」と言えるのは1台の中までで、外はまだ何も分かっていない。**

## 4. 「書いたが繋がっていない」もの

**もう無い。** 3〜4人の直結(P2P)は既定で有効。中継サーバーは今まで通り
書いてあるだけで既定オフのままだが、これは「繋がらなかった回線への保険」
という元々の役割どおりで、無くても3〜4人は繋がる想定。

| | 場所 | 既定 | 動かすには |
|---|---|---|---|
| 直結(P2P)の3〜4人 | `src/coop.js`(`RtcHostTransport`/`RtcGuestTransport`) | **オン** | — |
| 中継サーバー(保険) | `server/` + `index.html:12` | **オフ** | サーバーを立てて URL を書く(任意) |

参考に、**環境変数が要る**機能(これらは Vercel 側の設定で既に動いている):

| 機能 | 要る設定 |
|---|---|
| ふたりでプレイの出会い | `UPSTASH_REDIS_REST_URL` / `_TOKEN` |
| 直結の補助(TURN) | `TURN_URLS` / `TURN_CREDENTIAL`(無くても既定で動く) |
| AIステージ生成 | `GEMINI_API_KEY` |
