## 2. オフラインと保存

| 確かめたこと | 結果 |
|---|---|
| app shell がキャッシュに入る | `edu-v5-shell` に **37件** |
| 回線を切って起動できる | **できる** |
| 回線を切って遊べる | **遊べる** |
| オフラインで書体が読める | Baloo 2 **読める** / Outfit **読める**（`fonts/` に同梱） |
| `localStorage` が例外を投げる環境で起動できる | **できる** |
| 同じ環境で遊べる | **遊べる** |
| インストールできる manifest | **満たす**（fullscreen / portrait / icons: 192x192 any, 512x512 any, 512x512 maskable） |

> **ここはネイティブ化の判断に直結する。** 「オフラインで遊べる」も
> 「ストレージが消えても落ちない」も、すでに Web のまま成立している。
> 最後に残っていた書体の穴も、同梱して塞いだ（ネイティブ化は要らなかった）。

## 3. 画面の破綻

検査したビューポート: 8種 × 日英。

**HTML で置かれている要素に、画面外・重なり・小さすぎるボタンは無かった。**

> **ここで判定できるのは HTML で置かれた数個の要素だけ。**
> 題字もボタンの文字もキャラのカードも canvas に描かれていて、DOM には存在しない。
> docs/layout.md が記録した破綻（題字と説明文の重なり、カードの棒のはみ出し）は
> **この検査では捕まえられない**。撮った画像は `tools/probe/shots/` にあるので、
> そこは人が見る。canvas 側まで機械で見るには、ゲームが自分の描画矩形を
