# サーバーはどこに立てて、いくらかかるのか / iOS と Web でどう違うのか

> 2026-07-29。**帯域の数字はこのゲームの実測から計算したもの**で、一般論ではない。
> 価格は 2026年7月時点。各社とも変わるので、契約前に必ず本家で確認すること。

## 1. まず「何がお金になるのか」

中継サーバーの費用は、ほぼ**サーバーから出ていくデータ量(送出/egress)**で決まる。
CPU もメモリも余っている(50部屋で CPU 20%・96MB)。**帯域だけが効く。**

実測: ワールド配信は 1通 **2,211バイト**を毎秒15回。位置は約60バイトを毎秒20回。
中継はそれを部屋の人数ぶんに複製するので:

| 人数 | サーバーの送出 | 1時間あたり |
|---|---|---|
| 2人 | 35 KB/秒 | **122 MB** |
| 3人 | 72 KB/秒 | 252 MB |
| 4人 | 111 KB/秒 | **391 MB** |

**4人プレイは2人の3.2倍の帯域を食う。** 人数が増えると複製先も増えるため。

## 2. どこに立てるか — 3つの選択肢

| | 固定費/月 | 込みの帯域 | 超過分 | 東京から近いか |
|---|---|---|---|---|
| **Hetzner CX22** | $4.59 | **20 TB** | ほぼ気にしなくていい | シンガポール(東京リージョンは無い) |
| **Fly.io** shared-cpu-1x | $2.00 | 0 | **$0.04/GB**(アジア) | 東京にある |
| **AWS EC2** t4g.small | 約$12 | 100 GB/月 無料 | **$0.09/GB** | 東京にある |

### 実際の月額(共闘の総プレイ時間で計算)

**月1,000時間**(=毎日33時間ぶん遊ばれる。友達内でよく遊ばれている規模):

| | 2人プレイ中心 | 4人プレイ中心 |
|---|---|---|
| **Hetzner** | **$4.59** | **$4.59** |
| Fly.io | $6.66 | $16.92 |
| AWS | $13.48 | $36.56 |

**月10,000時間**(=毎日330時間。数百人が毎日遊ぶ規模):

| | 2人プレイ中心 | 4人プレイ中心 |
|---|---|---|
| **Hetzner** | **$5** | **$5** |
| Fly.io | $49 | $151 |
| AWS | $108 | **$339** |

### 結論: AWS は、この用途では一番高い

**AWS の弱点はまさに帯域**($0.09/GB)。このゲームは計算をほとんどせず
データを流すだけなので、AWS の強み(豊富なサービス)が効かず、弱みだけを踏む。
規模が出ると **Hetzner の70倍**になる。

**推奨: 最初は Fly.io、遊ばれ始めたら Hetzner。**

- **Fly.io** — 東京にサーバーを置けるので**遅延が一番小さい**。
  小さく始めるなら月$2〜7。デプロイも一番簡単
- **Hetzner** — 帯域が20TB込みなので、**どれだけ遊ばれても月$4.59で頭打ち**。
  ただしシンガポールなので東京から往復+70ms 程度。それでも直結が張れない組にとっては
  「繋がらない」よりずっといい
- **AWS** — この用途では選ぶ理由がない

> 上の表には**まだ入れていない節約**がある: 圧縮(permessage-deflate)。
> JSON のスナップショットは繰り返しが多いので、入れれば帯域は 1/3〜1/5 になる見込み。
> Fly.io の $151 が $30〜50 になる計算。人数を増やすときに効く
> (`server/README.md` に「意図的にやっていない」として記録済み)。

## 4. iOS アプリとして出す場合 vs Web のまま

### かかるお金

| | Web(いまの形) | iOS アプリ |
|---|---|---|
| 出す費用 | **$0** | **Apple Developer Program 年$99** |
| 審査 | 無し | あり(数日〜。落ちるとやり直し) |
| 更新 | git push で即 | **毎回審査**(緊急修正でも数時間〜数日) |
| 課金するなら | 決済を自前で用意 | Apple が15〜30%取る |
| サーバー費 | 上の表と同じ | **同じ**(同じ中継を使う) |

Android(Google Play)は**登録が$25の一度きり**で、iOS より安く早い。

### 一番の問題はお金ではなく「4.2 リジェクト」

**Web を包んだだけのアプリは Apple に落とされる可能性が高い**
(ガイドライン 4.2 Minimum Functionality —「サイトを束ねただけ」と判断される)。
`docs/store-readiness.md` に書いたとおり、通すには Game Center・課金・触覚・
プッシュ・完全オフラインのどれかを**ネイティブで本気で足す**必要がある。

**Google Play は事情が違い、TWA/WebView 方式が通常どおり受理される。**

### それぞれの得意

| | Web が勝つところ | iOS アプリが勝つところ |
|---|---|---|
| 遊び始めるまで | **QRを読む → 即プレイ。インストール不要** | ストアで検索 → DL → 起動 |
| 4人集める | **URLを送るだけ。全員が今すぐ入れる** | 全員がインストールを終えるまで待つ |
| 見つけてもらう | 自分で広める必要がある | **ストアの検索・ランキングに乗る** |
| 課金 | 自前で用意 | **仕組みが揃っている** |
| 通知で呼び戻す | 弱い | **強い** |

**このゲームの芯は「QRをかざしてその場で4人」なので、Web のほうが噛み合っている。**
インストールを挟むと、いま一番いいところが消える。

## 5. 順番の提案

1. **中継を Fly.io に立てて(月$2〜7)、Web のまま4人を遊べるようにする**
2. 家庭の外の人に遊ばせる。判定は「言われなくても2回目を始めるか」だけ
3. 遊ばれ始めたら **Hetzner へ移す**(帯域込みで頭打ちにする)か、**圧縮を入れる**
4. 数字が付いてから **Android(TWA・$25)**。iOS より速く、判断材料が得られる
5. iOS はその後。**$99 + 4.2 のリスク**を、実際の利用数を見てから引き受けるか決める

いま iOS に突っ込むのは、**一番お金がかかり、一番落とされやすく、一番学びが少ない**。
